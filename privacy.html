プライバシーポリシー

この道具は、持ち主が自分のチャンネルを許可したときだけ、YouTube のデータを読みます。

読むもの

自分のチャンネルの動画の一覧と、再生数・表示回数・クリック率・見られた入口などの数字です。許可の範囲は「見るだけ」で、動画を上げる・消す・書き換えることはしません。

使い道と保存

読んだ数字は、持ち主のパソコンの中だけに保存し、自分の動画作りの参考にします。ほかの人に渡したり、売ったり、広告に使ったりはしません。

許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。

この道具が Google API から受け取った情報の使い方は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
